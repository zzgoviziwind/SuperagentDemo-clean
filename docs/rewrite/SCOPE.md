# Windows 候选版行为范围

“完整移植”是交付目标，实际通过情况以独立验收记录为准。`surface.json` 逐项定位冻结源码中的 HTTP 入口、模型表和配置名，可运行 `python deploy/rewrite/inventory.py` 重新抽取。前端导航来自冻结的 `apps/web/src/main.tsx`。

| 用户入口与行为 | 交付选择 | 模式与兼容要求 |
| --- | --- | --- |
| 登录、管理设置、角色/授权、审计、预算 | 完整移植 | token/cookie、本地身份、旧 owner 与无 grant 的身份；用量与未知预留可对账 |
| 事件中心、来源消息、列表筛选、逐事件核验、跟进 | 完整移植 | 保留历史事件组、订阅和任务整数编号；组与消息分开计数 |
| Worker 工作台、分析/修复/回复、历史、产物 | 完整移植 | 权限、同轮证据、消息控制及取消恢复，历史 artifact 可无 attempt |
| 项目设置、本机 Codex、单仓/多仓 | 完整移植 | 本机已有登录须显式选择；允许目录、分支、只读范围与已绑定 thread 保留 |
| 运行状态、钉钉与 Redmine、飞书私聊审批 | 完整移植 | 默认关闭；监听范围、身份映射、自回声、工单快照、游标、目标绑定、账本和卡片复用同一决定 |
| 事件规则、静默、草稿、接受、未知回复 | 完整移植 | 默认人工；真实发送由显式策略及当前版本约束；跨午夜和历史哈希兼容 |
| 执行尝试、决定/上下文清单、后台投递 | 完整移植 | WP1 legacy/attempt；WP2 legacy/decisions；WP3 inline/worker、v1/v2；旧记录保持可读 |
| Router、语义分流、Watchdog 与会话桥接 | 完整移植 | 保留开关与历史；幂等及授权边界分别复验 |
| 远端共享卷 daemon | 保留原服务承载 | Windows TS 包支持读取、维护节点绑定；实际远端派发由冻结 Python 控制器和原 daemon 配对承载。转回 Python 前停 TS 并检查租约、未知记录；绑定远端的项目不得改在本机执行 |
| 现场记录、时间轴、人工候选决定与实现入口 | 完整移植 | 冻结快照中管理员可进入；保留记录与任务关联 |
| 现场记录 OCR、媒体提取与可选专用处理 | 保留原服务承载 | 安装额外 Python 媒体组件，由原表保存历史；安装路径、可用性及错误反馈须验收 |
| 已承诺的 Linux / Docker / PostgreSQL 部署 | 保留原服务承载 | 此次 Windows/SQLite 包独立，原 Python 入口、Compose、库版本在原线维护；跨库迁移及 Windows 包对其他平台的支持待产品决定 |
| 其他 Agent 驱动、Electron、第三方插件、ChatGPT 原生自动建聊 | 尚待产品决定 | 无默认入口或未提供稳定契约，不在本次安装包启用 |

基线 commit 上没有 WP1–3 和现场记录。冻结的工作树已经具备这些源码。原工作区当时的部署进程、实际开关和已登录渠道没有在本轮访问，现场环境是否运行同一代码无法由 Git HEAD 得出。

### 安全差异

工作台访问历史任务、详情、附件及统计使用同一可见性条件。旧版存在部分列表/详情直接返回全量记录的路径，跨 owner 读数据不能作为通过预期。潜在副作用在重启后必须冻结；过期控制器的迟到写及未知投递的自动重发均须拒绝。Windows 下需观察整个子进程树及退出状态，不能以父进程已退出认定执行已停止。
