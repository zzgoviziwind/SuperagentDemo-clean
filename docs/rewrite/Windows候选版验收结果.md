# Windows RC2 验收结果

本候选用于独立 Windows 用户目录下试用。本地执行的程序版本是 `0_2_0-rc2-0fa9b3e`，源码提交是 `0fa9b3e8d7e182eebe080410f896db9b79271b82`。安装 EXE 的 SHA-256 为 `043adfd45a9d635f429f5392e7b1f7ca6ad6632f702346b97a9a410e1ee9d89c`，内嵌 ZIP 与单发 ZIP 的 SHA-256 同为 `bf4593ef65608835c766b43349ba8fdfea5a14609472fe1cd47a7f22da48c9dc`。

重启时，缺少本轮回执的派发须人工核验。对于没有进程退出证据的历史 Router 或巡检操作，工作台会继续显示未知。远端节点实际派发与既有 Linux/PostgreSQL 部署沿用原 Python；需要原 WP1 或 WP3 开关语义时也可按随包说明回切。媒体识别依赖本机另行配置的组件。

**最终包的接口差分。** 冻结 Python 与包内程序均实际调用了 119 个方法与路径，每端串行 238 次。71 项的正例业务抽查一致，其中 67 项存在响应头差异。32 项存在返回字段或持久记录差异，6 项存在行为差异，另有 2 项协议拒绝、4 项前置条件拒绝，以及 2 项交由 Python 承载的入口。非法项目字段在 Python 返回 500，在候选版返回 422。附件重试被严格对照标成副作用差异，两个服务停机后读回的作业均为 failed、结果均为空，错误字段的表达仍有区别。

钉钉关闭时，候选版拒绝群查询与私聊历史同步；本机模型或退出证据缺失时，部分历史会话需要核验。其他差异包括响应缓存策略、启动恢复新增审计造成的事件编号偏移、权限收紧及能力描述。每个入口的正负例、数据库变化和差异位置记录在验收压缩包内 `tests/rewrite-acceptance/evidence/candidates/3d1aa76d066f17ce1326b954aabcd19946e0045101078983b3645cee62a67557` 下。

本次使用合成业务数据和隔离端口。真实 Codex 登录及计费、真实钉钉、飞书与 Redmine、真实语音/OCR 模型和全新 Windows 虚拟机均待现场验收。安装件未签名。

实包正常自动流程连续两轮通过，逐轮证据在 `tests/rewrite-acceptance/evidence/phase1-package-ubc48rcc`。原测试在自动建稿后又调用人工建稿接口，一轮看到了相同正文的两条草稿，断言在发送前停止。受控复现中，运行记录把草稿 2 绑定到自动决定，人工请求创建了草稿 3。同一回复可以出现两条待处理记录，该场景没有证明发生重复外发。使用工作台时先检查任务下已有草稿，避免为同一次回复再次手建。

**实包验证。** 总计 1,500 次 HTTP 观测包括 476 次串行请求、952 次逐接口并发请求及 72 次混合请求。每侧重复提交同一事件 12 次，仅新建一个任务。候选版在两个远端入口共返回 8 次预期的 503，Python 并发创建订阅出现一次 500。回切专项 2/2、账本专项 4/4 通过。

Windows 实装验证了 RC1 升级到 RC2 后，两版各自创建的任务均可读。故意启动失败能恢复，手动回滚、切回、卸载后重装均保留数据。实装的 Git 可以枚举临时双仓分支。停止候选版后，冻结 Python 在同一 SQLite 文件中读回数据，随后 Windows 候选版成功接回。Edge 完成桌面、平板和窄屏检查，保存 15 张截图；窄屏事件页截图停留在加载状态，该帧不能证明加载后的最终布局。前端回归 110/110，后端最终串行回归 105/105。与双端回放同时运行时，部分进程启动和等待断言曾超时。
