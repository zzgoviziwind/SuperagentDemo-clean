# 事件中心与协作闭环验收

日期：2026-11-14。

## 本轮实现

- 默认进入事件中心；移除独立任务导航及旧列表，按事件组聚合相关事件。原任务详情的执行、审批、验收能力在事件组中保留。
- 增加事件组列表与详情 API，支持来源事件、过程事件、逐事件核验、重新打开、持续跟进管理、协作请求。多目标投递显示原始事件，避免副本重复。
- 逐事件结论保存在追加式事件记录中，不改写来源消息，不把 Worker 执行结束视为所有事件已解决。不同组对同一来源的处理结论相互独立。
- 全局订阅页只读；停止/恢复已有显式跟进在事件组内完成。历史问题引用继续自动关联，群消息关联不会自动扩大成全群订阅。
- Worker 最终结构化报告可请求最多三个只读子 Worker；子 Worker 不自动递归。界面可明确委派分析或修改型协作，重复请求键不重复创建。
- 协作结果作为新事件回流主 Worker 上下文。暂停和终态组保存结果但不自动恢复，运行/审批/资源等待或未知执行状态不强行推进；可恢复组更新版本、使旧审批过期并排队续处理。
- Router 提示规则强化同问题补充、纠正与反馈的关联判断。内部协作结果由确定性处理器回流，不把它描述为已调用模型 Router。
- 保留 Task 表、旧 API、主 Worker 与内部执行记录的对应关系及历史数据。本轮不是删除或迁移数据库模型。

- 前端全套：14 个文件、64 项通过；最后展示文字与权限按钮调整后，App/EventGroups 12 项定向复验通过。

- 后端扩展回归初次为 53 项通过、1 项失败。失败定位为 Windows 模拟 idle peer 未用 UTF-8 读取新增中文提示，已修复测试替身。

- 新增真实本机 HTTP + 调度器 + 模拟模型进程的协作闭环验收 1 项通过：主 Worker 发起协作、子 Worker 使用独立工作区只读分析、结果进入原事件组及会话、主 Worker 恢复到待核验。
- 初次普通执行环境禁止本机连接，相关测试曾失败；允许本地连接后完成上述验证。没有将这些环境失败隐去或当成业务通过。
- 本地隔离预览已重启，`http://127.0.0.1:8876/api/v1/event-groups` 返回三个既有事件组及待核验数。仅使用已有模拟数据，调度与真实渠道保持关闭。

## 验收边界

- 真实模型自主协作、真实钉钉/Redmine 接入未在本轮重新验收；上述模型进程为离线测试替身。
- 当前可用浏览器工具没有网页浏览器通道，未完成浏览器视觉验收；接口、组件交互、构建与协作闭环已分别验证。
- 当前每个事件组有一个主 Worker，通过关联子事件组协作；未实现任意更换主 Worker 或把现有团队成员自动抢占到当前组。
- 自动协作在当前轮报告保存且执行停止后消费，不是在模型流式生成途中创建子 Worker；自动委派只读，修改型分工由用户明确选择。
- 本轮没有提交 Git、对外发送内容或部署业务服务。保留工作区已有改动。
