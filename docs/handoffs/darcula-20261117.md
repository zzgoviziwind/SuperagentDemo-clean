# Darcula 深色 · 2026-11-17

「内容区配色」新增第五项 Darcula 深色。参考 [JetBrains 的 Darcula 界面主题](https://www.jetbrains.com/help/idea/user-interface-themes.html)，为内容底、列表、详情、表单、弹窗、选择态和业务状态分别配置深色，不动四套浅色。切换即时生效并沿用已有的浏览器本地记忆。

代表性文字对比：详情正文 10.92:1、选中背景上的辅助字 4.60:1、主按钮白字 6.76:1、六种事件状态最低 7.14:1。仅代表上述配色组合。

使用 Microsoft Edge、项目 Playwright 和 8877 隔离模拟后端，覆盖 1440×1000、1024×900、390×844。证据位于 `.test-tmp/design-workflow-visual/darcula-1b-20261117/` 和 `.test-tmp/design-workflow-visual/darcula-2-20261117/`。

第一轮三项通过；实际打开桌面事件及管理设置、窄屏表单截图，发现事件计数和表单次级按钮仍带浅色背景、管理设置摘要分隔线过亮。已修正并增加弹窗按钮背景检查。未改正式服务、真实渠道及业务库。

第二轮全量回归 23 项通过，桌面默认浅色下的模型设置用例超时一次；平板和窄屏同项通过。桌面单独复验（`darcula-desktop-recheck-20261117`）的深色与模型设置两项均通过。打开最终桌面事件、窄屏表单和平板 Worker 截图，确认计数、次级按钮及会话辅助信息已正确显示。最终构建通过。
