# 事件执行进度首屏

事件详情首屏显示当前执行阶段、可用的运行或核验时间、阻塞和下一步。核验原因关联当前目标和执行版本；无法定位到本轮证据时，仅显示已知的状态或记录缺口。查看核验记录会展开依据，补充信息会聚焦输入框。恢复仍通过原来的版本校验操作。

设计参照：GOV.UK Task List 将状态与可操作入口并列；USWDS Step Indicator 强调当前阶段的视觉优先级，本页流程会分支，故不画固定步骤；Atlassian Lozenge 用短文本标明状态，本页以正文解释原因，不要求用户单凭徽标推断。

两轮在隔离预览和 Microsoft Edge 检查 1440×1000、1024×900、390×844，使用模拟的只读核验受阻数据，阻止浏览器写入接口。第一轮截图确认信息层级和换行，发现「待补充」徽标仍会误导。第二轮改成「核验受阻」，核对了据实显示的权限提示，以及主按钮、焦点和窄屏溢出；截图位于 `.test-tmp/design-workflow-visual/execution-progress-round2/results`。
