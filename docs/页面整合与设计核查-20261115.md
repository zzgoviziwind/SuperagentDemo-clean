# 页面整合与设计核查（2026-11-15）

本轮核查主导航所有页面的事件组用语和入口：事件中心、执行会话、架构、订阅、运行状态、项目/管理设置、演示、完整消息记录。用户界面统一“事件”；后端 event-groups 标识保留以兼容历史。

旧事件组详情不再作为另一个主页面：处理、审批、来源核验等能力收进事件操作面板，关闭回到原事件。跨会话按任务ID恢复事件，直接读取事件详情，不依赖第一页或外部来源消息，因此人工事件也可定位。

产物空白根因：trace只含产物摘要且无task_id/content，旧前端误过滤。现读取/tasks/{id}完整产物，按revision区分当前与历史，不以取消或无当前版本证据抹掉历史结果。

来源回复是独立交付记录：草稿、获批待发、拒绝、审批失效、发送成功、发送失败、结果未知分别呈现。修复/开发交付的报告、差异和测试不与渠道回复混合；当前尚未实现的部署/发布证据不会伪造。

设计基线：冷调浅色、安静克制；标题及正文Segoe UI / Microsoft YaHei，基础16px，阶梯12.8/16/20/25/31.25；背景#eef3f6、卡片#f8fafc、正文#263c4a、强调#167c82；4px间距、区块32px、卡片20px、12px圆角；180ms cubic-bezier(.16,1,.3,1)，支持减少动画。新增样式不采用纯黑纯白纯灰。历史style.css仍含旧组件局部色值，不能宣称全量设计token迁移已完成。

验证：原70项前端测试通过；新增发送状态、跨页定位和完整产物读取回归另行执行。无后端行为变更，无真实发送或部署。
