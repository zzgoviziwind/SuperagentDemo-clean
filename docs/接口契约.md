# 模块接口契约

所有会话以此约定并行实现；必要变更由总控统一通知。

## 文件与运行

Python 包 `superagent`，应用入口 `superagent.main:app`。运行 `python -m uvicorn superagent.main:app --host 127.0.0.1 --port 8765`。API 前缀 `/api/v1`，JSON UTF-8；时间用 UTC ISO8601，界面本地化。错误形状 `{ "detail": "可读说明" }`。开发默认无真实连接，显式 demo 仅用于示范，不伪装真实执行。

## HTTP 契约

- `GET /health` → `{status,version}`。
- `GET /api/v1/overview` → `{counts: {状态: 数量}, active_tasks: [], pending_approvals: [], connectors: []}`。
- `GET /api/v1/projects` → 项目数组。
- `POST /api/v1/projects` / `PATCH /api/v1/projects/{id}` → 项目对象。
- 项目字段：`id,name,repo_path,base_branch,test_command,allowed_paths:[],dingtalk_chat_ids:[],redmine_project_ids:[],enabled,created_at`。test_command 仅管理员可配置的命令，不从消息拼接。
- `GET /api/v1/tasks?status=&project_id=` → 任务数组。
- `POST /api/v1/tasks` 请求 `{title,goal,project_id,acceptance_criteria?,source?:"web"}` → 任务。
- 任务字段：`id,title,goal,project_id,status,revision,state_version,control_version,source,source_ref,created_at,updated_at,last_error,codex_thread_id,codex_turn_id,workspace_path`；可增加字段但不删除以上字段。
- `GET /api/v1/tasks/{id}` → `{task,events:[],artifacts:[],approvals:[]}`。
- `POST /api/v1/tasks/{id}/messages` 请求 `{content,change_goal:false,expected_state_version?}` → 事件。
- `POST /api/v1/tasks/{id}/controls` 请求 `{action:"start|pause|resume|cancel|retry",expected_state_version?}` → 任务。
- `POST /api/v1/tasks/{id}/acceptance` 请求 `{accepted:true,comment?,revision}` → 任务。
- `GET /api/v1/approvals` → 审批数组；`POST /api/v1/approvals/{id}/decision` 请求 `{decision:"approve|reject",action_hash}`。
- `GET /api/v1/connectors` → 状态数组，每项 `{id,name,configured,enabled,status,last_error,last_seen}`。
- `GET /api/v1/settings` → 脱敏配置；`PATCH /api/v1/settings` 仅非秘密设置。
- `GET /api/v1/artifacts/{id}` → 可鉴权的文件或内容；不能返回任意用户路径。
- `GET /api/v1/events/stream` → SSE，前端也可有界轮询任务列表。
- `POST /api/v1/events` 为内部/本地测试注入，真实部署需要管理员身份，不暴露为未鉴权公网入口。

统一任务状态：queued/running/waiting_input/waiting_approval/waiting_resource/paused/review_ready/completed/failed/cancelled。默认人工验收；completed/cancelled 新需求另建关联任务。

## 运行时模块 契约

`superagent.runtime.codex` 提供 `CodexAppServer` 类：

```python
client = CodexAppServer(executable: str | list[str], cwd: str, config: dict | None = None)
await client.start()
thread = await client.start_thread(cwd: str, instructions: str = "")  # dict 含 id
await client.resume_thread(thread_id: str)
turn = await client.start_turn(thread_id: str, prompt: str)  # dict 含 id
await client.steer_turn(thread_id: str, turn_id: str, prompt: str)
await client.interrupt_turn(thread_id: str, turn_id: str)
async for event in client.events(): ...  # 原始 method/params、server request id
await client.respond_approval(request_id, decision: str)
await client.close()
```

此接口是内部封装，底层严格按本机 Codex schema 与官方文档核验。禁止默认全权限。Codex 发现、会话状态持久化由控制层配合；运行时不自行发钉钉/Redmine 消息。

`superagent.runtime.workspace` 提供 `prepare_workspace(repo_path, base_branch, task_id, workspaces_root) -> dict`（含 path/base_sha/branch），`collect_changes(path) -> dict`（含 diff/stat/status），均需路径和 Git 状态校验，拒绝默认吞掉未提交改动。runtime 额外接口以 handoff 说明。

## 接入模块 契约

统一事件字典：`{source,external_id,event_type,actor_id,thread_id,project_external_id,issue_id,content,occurred_at,attachments:[],metadata:{}}`。业务身份需映射；不得将外部正文当授权。

`superagent.connectors.redmine.RedmineClient(base_url, api_key)`：异步 `list_updated_issues(updated_since, project_id=None) -> list[dict]`、`get_issue(issue_id) -> dict`、`add_comment(issue_id, content) -> dict`、`close()`。网络超时、分页、权限和未知写结果要明确处理。

`superagent.connectors.redmine.RedminePoller(client, emit, state_store, project_ids, user_id)`：异步 `poll_once()`，emit 为 async callable(event)，state_store 提供 get/set 的适配约定由接入会话写明。

`superagent.connectors.dingtalk.DingTalkListener(executable, emit, ...配置)`：异步 start/stop，读取 DWS NDJSON，等待 ready，self-loop 过滤。`DingTalkClient` 封装按配置向明确 conversation/message 发送回复；不在开发时真实调用。

连接器不要依赖数据库具体实现；控制层负责 emit 持久化、身份、去重和路由。外部动作先持久化审批和发布账本，网络超时视为结果未知。

## 集成与验证

控制后端负责可配置 Scheduler（Codex runtime 可用时真实运行），使用连接器统一事件。其他会话仅写所有权目录；不因依赖未就绪停工，按此契约写单元/协议测试。根目录 Python 配置由控制后端所有，不互相覆盖。根 README、部署和端到端验收归总控及验收会话。
