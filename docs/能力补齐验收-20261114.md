# 能力补齐与预览恢复验收

2026-11-14，总控集成四个独立开发会话，保留既有未提交修改。本轮没有提交、推送、替换 8765 实例或向真实业务渠道发送内容。

## 可使用入口

[新版预览](http://127.0.0.1:8876) 使用独立后台进程；上一轮预览依赖临时终端，进程退出后链接失效。本轮新增 `deploy/start-preview.ps1` 与 `deploy/stop-preview.ps1`，按 PID 和启动时间识别本预览进程，重复启动复用，端口被其他进程使用时拒绝覆盖。

演示数据库 `data/preview-service/database/preview.db`，日志和进程记录保存在 `data/preview-service`。默认关闭真实接入、对外发送、自动执行与模型服务。重启计算机后需再次运行启动脚本；未安装系统自动启动任务。

首次 Watchdog 检查误将正常 userMessage 识别为工具活动，已修复协议白名单并补回归；原 unknown 记录保留，未自动重放。修复后的新任务真实巡检验收单独记录，不覆盖失败证据。

修复后真实 Watchdog 对新任务完成审查，结论 observe/applied=observe，理由为新分派排队任务尚无执行记录，现有证据不足以判定停滞或偏离。状态 completed，证据 `.test-tmp/v3-real-model/watchdog-result.json`；thread `01a1d814-91dc-7eb3-8f5a-b83e491f9e04`，turn `01a1d814-983b-7d51-b7cf-df0a28ec0b23`。真实模型验证覆盖判断与落库；暂停、停止失败及版本过期由离线回归覆盖。
