# 现场记录音视频后台处理与验收

## 使用与处理

在「现场记录」选择项目和记录名称，上传一个音频或带语音的录屏。可额外上传截图并填写距原文件开头的秒数，支持毫秒精度。提交后可离开页面，任务状态从后台读取。完成后打开候选审核。失败后可人工重试，进程中断或过期尝试没有自动重跑模型。

后台先使用本机 faster-whisper 转写，依据词级时间和断句定位问题，再让 Codex 根据转写拆分事项。录屏从相关语音片段抽取少量帧，已上传截图在对应时间覆盖的事项优先使用现有画面。上传截图和自动抽帧合计最多 5 张。第二轮只把语音文字和这些图片交给具备视觉能力的 Codex 核对。原视频和原音频保存于本机，审核时读取原始字节。 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) · [PyAV 定位与解码](https://pyav.basswood.io/docs/stable/api/container.html)

截图时间要以同一个音频、录屏或已导入转写的时轴为准。覆盖同一时间的片段优先，空隙中的截图只提示 5 秒内最近的候选片段，并保留并列候选。时间关系只用于找线索，画面内容才决定是否引用。没有录屏时，可以提交语音和手动截图，或继续使用已有转写的时间轴 JSON 加截图。脱离语音及转写的截图仍可做独立图像整理。

点击候选证据中的时间段，播放控件定位到原音视频对应位置，播放到片段末尾暂停。截图链接打开原图。候选须经人工审核才进事件中心，入站先排只读分析，实施仍须人工确认。

## 启用

更新主环境依赖，以支持 multipart 上传。在项目内用独立 Python 3.12 环境安装 `requirements-field-media.txt`。`SUPERAGENT_FIELD_MEDIA_PYTHON` 指向该环境的 Python。`SUPERAGENT_FIELD_WHISPER_MODEL` 指向已下载的本地 CTranslate2 多语言 Whisper 模型目录。目录应含 `model.bin`、`config.json` 和 `tokenizer.json`，下载后可以离线转写。工作台连接 Codex 并使用支持图像输入的模型。上传支持 MP4、WebM、WAV、MP3 和 M4A，最大 150 MiB 和 45 分钟，转写受原时间轴 300 片段、30,000 字的上限约束。浏览器播放能力还取决于文件实际编码。

## 验收

使用本机合成的英文讲解和虚构医院界面生成 26.750 秒 MP4，外加一张人工上传的第 19 秒截图。真实本机 Whisper Base 和真实 Codex 得到两条事项。

| 事项 | 语音区间 | 图像证据 |
| --- | --- | --- |
| 报告预览未显示已保存的科室小结 | 00:00–00:06.800、00:07.740–00:10 | 自动抽帧 00:03.500 |
| 导出清单增加最终审核时间列，保留审核人列 | 00:12–00:17.380、00:18.480–00:24.480 | 单独上传的 00:19 截图 |

真实接口验收确认了原图读回、媒体 Range 返回 206 且字节一致、审核前现场事件为 0、批准后新任务为只读、分析生成前实施被拒绝。另用实际 WAV 验证音频解码及词级转写。这组样本没有实际医院录音、中文口音或长视频负载。

后端回归 35 项、前端回归 15 项和前端构建通过。Edge 首轮在 1440×1000 和 390×844 检查上传、后台完成和跳到第 12 秒。审查时首轮截图仍显示播放器加载状态，因此复验明确等待目标画面完成解码，并检查片段到点暂停。复验在 1440×1000、1024×900、390×844 通过 12 项浏览器检查。页面测试复用真实模型结果和原始样本字节，实际后台处理由独立 HTTP 验收执行。两轮截图路径为 `.test-tmp/design-workflow-visual/2026-11-18T08-32-29-631Z/results/` 和 `.test-tmp/design-workflow-visual/2026-11-18T08-35-35-423Z/results/`。

可按 `tests/fixtures/field_media_sample.py` 将两个合成 WAV 与界面截图打包，再使用项目 Python 运行 `tests/fixtures/field_media_live.py <录屏> <独立截图> <新证据目录>`。脚本使用当前本机登录和独立数据库。媒体样本位于 `.test-tmp/field-media-sample/meeting.mp4`，实际输出位于 `.test-tmp/field-media-live-r2/record.json`。
