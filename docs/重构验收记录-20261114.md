## 真实 Codex 讨论验收

使用专用 Codex 登录目录 `data/codex-state`，独立模拟数据库与 Router 工作目录。模型 `gpt-6.1-sol`，推理强度 `medium`。Worker 自动执行和外部交付始终关闭。

1. 第一次准备因模拟库尚未创建预算账户而失败，未创建线程；失败消息留存。
2. 补齐模拟库预算配置后，第一轮成功创建线程并回答当前任务编号和暂停状态。
3. 第二轮恢复同一线程，继续讨论下一步建议。两轮都收到真实 `turn/completed`，且有可见助手答复，最后会话状态 `idle`。
4. 两轮线程 ID 相同：`01a1d5d1-bf69-7952-933f-a8f765dd7cf6`。结构化记录保存于 `.test-tmp/router-real-smoke/result.json`，含最初预算失败，未覆盖失败证据。
5. 该测试证明真实线程创建、恢复与回复持久化；不证明自动业务分派、跨应用聊天同步或所有原生工具完全隔离。真实模型轮次后增加的工具活动计数与清理保护由模拟协议回归验证。
